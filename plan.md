A portfolio agent for design students that turns scattered project materials uploaded to a google drive into a polished, portfolio-ready case study. Users define their portfolio guide once, and the agent analyses their materials, identifies missing information, structures the story, selects relevant visuals, creates a varied but cohesive layout, and reviews the final output for accuracy and consistency.

SKILL BREAKDOWN

Portfolio guide- user defines rules for visual style, writing style, case-study structure, and variation that the agent must follow when creating pages. This ensures projects feel like part of the same portfolio without every case study looking identical.

Copywriter- turns raw information and refers to portfolio guide to create a compelling design narrative.

Visual curator- determines which images matter and which image supports which section. MVP: chooses images and their placement. Final: MVP + recommended crop/aspect ratio for consistency.

Layout- creates page compositions based on the portfolio guide and selected visuals. Maintains visual consistency across the portfolio while allowing variation between individual case studies. MVP: use publicy avalible reliable text-and-image compositions. Final: Generate varied layouts and compositions for each case study using design logic.

Final Assembly- combines everything into a complete page

Critic- evaluates the draft for factual accuracy and adherence to the portfolio guide and missing information. Flags issues for the ggent to resolve before presenting the final draft. MVP: excluded. Final: Included in final.

OTHER COMPONENTS:

Framer MCP Integration- Once the user approves the final draft, use Framer MCP to build the case-study page in Framer, translating the approved content and layout into a Framer-based design. MVP: excluded. Final: Included in final.

Agent Role- Understands what actually happened in this project? Identify context (problem, insights, constraints), iterations and process, final solution, outcome. Establishes connections between the project's intent, design decisions and outcomes. Assesses whether sufficient information is available, identifies missing information, determines which skills are required and orchestrates them in the appropriate sequence. Reviews the generated case study against the Portfolio Guide and user requirements, then presents the draft to the user for feedback and coordinates revisions.

AI involvement: AI should handle the tedious work while the user remains responsible for approving key decisions as per their liking. This level of involvement will significantly reduce portfolio-building time without allowing the AI to misrepresent the designer's work by keeping the human in the loop
